# Triangle - зауваження до коду

## Triangle.java

1. **Немає валідації.** Можна створити трикутник зі сторонами 0 або від'ємними, або таким, що порушує нерівність трикутника (наприклад, 1, 1, 10).
2. **Конструктор за замовчуванням** створює трикутник 0, 0, 0, який не існує. Об'єкт має бути коректним одразу після створення.
3. **Змінюваний стан.** Сеттери дозволяють зламати інваріант після створення. Клас краще зробити незмінним (immutable).
4. **Нестандартні назви методів.** `takeA/putA` замість `getA/setA` (JavaBeans). Це збиває з пантелику й ламає сумісність з бібліотеками.
5. **Неясні назви.** `perim`, `equilateral` замість `perimeter`, `isEquilateral`. Булеві методи мають починатися з `is`.
6. **Дублювання обчислень.** У `area()` метод `perim()` викликається тричі. Півпериметр треба обчислити один раз.
7. **Зайвий `if/else`** у `equilateral()`. Достатньо `return a == b && b == c;`.
8. **Порівняння `double` через `==`** ненадійне для результатів обчислень. Для навчального прикладу допустимо, але варто це зазначити.
9. **`area()` для неіснуючого трикутника** повертає `NaN` без жодного попередження.
10. **Форматування.** Нерівні відступи (3 і 4 пробіли), зайві пробіли в `public  boolean  equilateral(){`, порожній рядок на початку файлу.
11. **`equals` оголошено `final`, а клас не `final`.** Якщо клас не призначений для успадкування, його слід оголосити `final`.
12. **Немає документації.** Відсутні Javadoc-коментарі до класу та методів.
13. **Немає пакета.** Клас лежить у default package.

## Main.java

14. **Не використовує `Triangle`.** Це шаблонний код IntelliJ, що не демонструє роботу класу.
15. **Залишки шаблону:** `@class ${NAME}`, `@project Default (Template) Project`, коментарі `//TIP`.
16. **`String.format("Hello and welcome!")`** без аргументів не має сенсу.
17. **Нестандартна точка входу** (`void main()`, `IO.println`) вимагає JDK 25. Для звичного коду краще `public static void main(String[] args)`.
18. **Назва файлу не відповідає змісту.** Немає оголошеного класу `Main`.

## Проєкт

19. **Немає README.md** (цей файл додано).
20. **Файли `.idea/` у репозиторії.** Налаштування IDE не мають бути в git, їх слід додати до `.gitignore`.

- Методи перейменовано: `perimeter()`, `area()`, `isEquilateral()`; сторони доступні як `a()`, `b()`, `c()` (п. 4-5).
- Півпериметр обчислюється один раз (п. 6).
- Додано Javadoc, виправлено форматування (п. 10, 12).
- Додано метод `isValid(a, b, c)` для перевірки без винятку.
- `Main` показує роботу `Triangle` і запускається на звичному `public static void main` (п. 14-18).
- `.idea/` і `*.iml` додано до `.gitignore` (п. 20).
- Пункти 8, 21, 22 залишено без змін (точність `double`, збірка, тести лежать поза межами цього завдання).
